Counterfactual fork & replay

Rewind a run to any super-step, edit the state (a field value, a message, a flag), and replay forward from there. The server rebuilds the graph and reruns it deterministically past the edit — this isolates whether ONE change explains a divergence, instead of guessing from the final output alone.

Import your own LangGraph

Point drift at any importable Python module exposing a build(model=...) function (returns a compiled graph) and an initial_state(query) function (returns a dict) — the same contract used by examples/targets/. Runs the same chaos + judge pipeline as the Test tab against it.

This dynamically imports and executes local code — same trust model as a Jupyter kernel. Only point it at code you wrote or trust; never expose this server beyond your own machine.
